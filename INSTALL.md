# Инструкция по установке и запуску

## Требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)

## Установка зависимостей

Откройте терминал в директории проекта и выполните:

```bash
pip install -r requirements.txt
```

Или установите вручную:

```bash
pip install cryptography sqlalchemy matplotlib pandas numpy
```

## Запуск приложения

```bash
python main.py
```

## Первый запуск

При первом запуске:
1. Система автоматически создаст базу данных `digital_ruble.db`
2. Будет создан Центральный банк РФ
3. Интерфейс откроется с 11 вкладками

## Использование

### Ручное создание пользователей и банков

1. Перейдите на вкладку "Управление"
2. Укажите количество пользователей и их тип
3. Нажмите "Создать пользователей"
4. Укажите количество банков
5. Нажмите "Создать банки"

### Запуск автоматической симуляции

1. На вкладке "Управление" выберите сценарий (1, 2 или 3)
2. Нажмите "Запустить симуляцию"
3. Симуляция будет работать 2 минуты реального времени
4. Все процессы будут отображаться в соответствующих вкладках

### Ручная работа с пользователем

1. Перейдите на вкладку "Пользователь"
2. Выберите пользователя из списка
3. Создайте цифровой кошелек
4. Пополните кошелек
5. Создайте транзакции или смарт-контракты

## Структура базы данных

База данных SQLite содержит следующие таблицы:
- `users` - пользователи системы
- `transactions` - онлайн транзакции
- `offline_transactions` - офлайн транзакции
- `smart_contracts` - смарт-контракты
- `blocks` - блоки блокчейна

## Устранение неполадок

### Ошибка импорта модулей

Убедитесь, что все зависимости установлены:
```bash
pip install --upgrade -r requirements.txt
```

### Ошибка при создании базы данных

Убедитесь, что у вас есть права на запись в директории проекта.

### Интерфейс не обновляется

Интерфейс обновляется автоматически каждые 2 секунды. Если данные не появляются, попробуйте нажать кнопку "Обновить данные" на соответствующей вкладке.

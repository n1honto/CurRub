# Имитационная модель платформы цифрового рубля

Полнофункциональная имитационная модель платформы цифрового рубля на Python с графическим интерфейсом.

## Возможности

- Моделирование участников системы (ЦБ РФ, финансовые организации, пользователи)
- Обработка онлайн и офлайн транзакций
- Реализация смарт-контрактов
- Консенсус RAFT для согласования транзакций
- Распределенный реестр (блокчейн) с криптографической защитой
- Полная визуализация всех процессов
- Хранение данных в базе данных SQLite
- Автоматическая симуляция с тремя сценариями нагрузки

## Установка

1. Установите Python 3.8 или выше

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Структура проекта

- `main.py` - точка входа приложения
- `gui.py` - графический интерфейс с 11 вкладками
- `system.py` - основная логика системы
- `models.py` - модели данных
- `participants.py` - участники системы (ЦБ, ФО, пользователи)
- `transactions.py` - обработка транзакций
- `consensus.py` - реализация консенсуса RAFT
- `blockchain.py` - распределенный реестр
- `crypto.py` - криптографические функции
- `database.py` - работа с базой данных

## Вкладки интерфейса

1. **Управление** - создание пользователей, банков, запуск симуляции
2. **Пользователь** - функции пользователя (кошельки, транзакции, смарт-контракты)
3. **Финансовая организация** - функции банка (запросы на эмиссию, транзакции)
4. **Центральный банк** - управление эмиссией и контроль системы
5. **Данные о пользователях** - таблица всех пользователей
6. **Данные о транзакциях** - таблица всех транзакций
7. **Оффлайн-транзакции** - таблица офлайн транзакций
8. **Смарт-контракты** - таблица смарт-контрактов
9. **Консенсус** - визуализация работы RAFT консенсуса
10. **Распределенный реестр** - визуализация блокчейна
11. **Анализ метрик** - графики и метрики производительности

## Сценарии симуляции

- **Сценарий 1 (Низкая нагрузка)**: 1,000 пользователей, 5 ФО, ~4,150 транзакций
- **Сценарий 2 (Средняя нагрузка)**: 10,000 пользователей, 10 ФО, ~41,800 транзакций
- **Сценарий 3 (Пиковая нагрузка)**: 50,000 пользователей, 15 ФО, ~208,500 транзакций

## Особенности реализации

- Криптографическая защита всех транзакций (RSA подписи)
- Полный жизненный цикл транзакций
- Обработка офлайн транзакций с синхронизацией
- Детектирование двойной траты
- Визуализация консенсуса и блокчейна
- Хранение всех данных в SQLite
- Автоматическое обновление интерфейса

## Примечания

- База данных создается автоматически при первом запуске
- Все данные сохраняются в файле `digital_ruble.db`
- Симуляция работает в отдельном потоке и не блокирует интерфейс
